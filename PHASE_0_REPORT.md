## Security

This is a public static preview with no business data or mutations. Private routes are not implemented and return generic 404s. Server-side RBAC and authentication remain Phase 2 requirements before private data is introduced. Security headers disable framing, enable nosniff, and limit browser capabilities. Search indexing is disabled. No passwords or raw backend errors are shown. Git exclusion for .env.local was verified.

## Remaining

ESLint 9 is deprecated upstream but selected because the current Next.js React/accessibility/import lint plugins do not support ESLint 10. TypeScript 6.0 matches the TypeScript ESLint peer range. Revisit these versions when plugin support changes. This is not a production-ready business application. Authentication, live data, roles, and business workflows are intentionally deferred.
